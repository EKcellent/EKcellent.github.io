# Esha Kapoor Portfolio

Deploy-ready React/Vite portfolio for GitHub Pages.

## Run locally

```bash
npm install
npm run dev
```

## Build locally

```bash
npm run build
npm run preview
```

## Deploy to GitHub Pages

1. Create or use the repository `EKcellent.github.io`.
2. Push these files to the `main` branch.
3. In GitHub, go to **Settings → Pages**.
4. Set **Source** to **GitHub Actions**.
5. Push to `main`; the included workflow deploys the site.

The site will be available at `https://ekcellent.github.io`.
